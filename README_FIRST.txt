NORTH STAR BAKERY | SOPHIA TOUCHSTONE 3

This folder expands the four-page HTML-only Touchstone Task 2 project with a shared external stylesheet.
Open index.html to view locally, or upload this entire folder to a GitHub repository.

FILES
- index.html (Home)
- products.html (Products)
- about.html (About)
- contact.html (Contact and Preorders)
- styles.css (shared responsive stylesheet)
- media/ (Sophia-provided North Star Bakery media; video optimized for file size)

Key design features: mobile-first CSS, Flexbox navigation and hero, media queries, 4 primary colors, 2 font families, keyboard-visible focus indicators, semantic HTML, screen-reader-friendly labels, alt text, and fallback media links.

NOTE: This is an educational site, not a deployed business. Hours, location, and prices are sample values. The form is a front-end demonstration and does not send a real order without a backend. The project repo link must be supplied by the student after upload to GitHub.
